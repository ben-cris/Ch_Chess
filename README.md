# 象棋辅助工具（Xiangqi Assistant）

基于 Python + PySide6 的**中国象棋棋局模拟、记录与分析工具**（含**揭棋**模式）。

> 定位说明：本程序**不是在线对战程序**；不连接任何对战平台；不自动操作其他软件；
> 不自动读取/发送棋步；不代替用户在现实中落子。
> 它的唯一用途是：**用户在现实中下棋时，手动把现实棋局录入程序**，程序模拟双方走棋，
> 并计算、推荐**用户自己的下一步最佳走法**。

## 功能

- 正常中国象棋：完整规则（车马炮兵将士相、九宫、楚河汉界、将军/将死/困毙、将帅照面、蹩马腿/塞象眼/炮隔子等），合法走法检查，胜负判断。
- 揭棋模式：暗子/明子模型；揭示事件由**用户选择真实身份**（程序绝不猜测）；揭示历史、被吃身份记录；按“预置 A”规则走棋（可配置，见 `docs/dark-chess-presets.md`）。
- 手动录入：红、黑双方都由用户录入；当前回合自动推进，也可手动切换/修正；支持悔棋、重做、编辑棋局（删除/改身份/设暗子/新增/重置）。
- AI 分析：分析**用户方**（你执红就分析红方）的下一步；显示推荐走法、评分、深度、思考时间、将军/吃子/杀棋；后台计算可取消；引擎异常自动降级，不崩溃。
- 内置开局库：正常玩法开局阶段直接套用常见棋谱主流招法（见 `docs/opening-book.md`），避免低深度搜索在开局走出“怪招”。
- 自动代走：**对家每走完一步，AI 自动代你走出最优一步**（可在设置/界面开关关闭）；刚走动的棋子带小圆环高亮，方便对照现实棋盘。
- 保存/加载：JSON 存档（模式/回合/棋盘/明暗身份/走法历史/揭示历史/被吃记录）。
- 日志、设置、单元测试、EXE 打包脚本。

## 使用流程（启动主菜单）

1. 程序启动先进入**主菜单**：选择游戏模式（正常玩法 / 揭棋）。
2. 选择**我执红方 / 我执黑方**（对家即另一方）。
3. 点“开始对局”。
4. 回合规则：红方先走。
   - 我执红方：第一步就是**你（红方）先走**，在现实棋盘走出后录入程序；
   - 我执黑方：红方（对家）先走，请先录入对家的第一步现实走法。
5. 轮到你走时：若“自动代走”开启（默认开），AI 会自动走出你的最优步并高亮刚走的棋子；你只需继续录入对家的现实走法。也可关掉自动代走，改为手动录入双方走法，或点“分析我的最佳走法”只看推荐。

> 说明：本程序是“现实棋局镜像/分析”工具——对家不是在线程序，对家的每一步由你在现实中观察后手动录入。
>
> 棋盘视角：**位于下方的一直是你（我方）**——你执红时红方在下；你执黑时程序会自动把棋盘翻转显示，黑方在下。
## 运行（PyCharm）

1. 用 PyCharm 打开本文件夹：`xiangqi_assistant/`（File → Open）。
2. 配置解释器：Python 3.11+（建议 3.13）。可在 PyCharm 里创建虚拟环境并安装依赖：
   - 方式 A：PyCharm 提示安装 `requirements.txt` 时点 Install；
   - 方式 B：终端执行
     ```
     python -m venv .venv
     .venv\Scripts\python.exe -m pip install -r requirements.txt
     ```
3. 运行 `main.py`（右键 → Run）。

命令行运行：`.venv\Scripts\python.exe main.py`

## AI 引擎

- **默认“自动”模式**：正常玩法只要检测到随包 Pikafish（`engine/bin/pikafish/`）就自动使用它；
  缺失/异常时自动退回内置搜索引擎，程序不会崩。揭棋始终使用内置引擎。
- **Pikafish（强引擎，推荐）**：世界顶级开源中国象棋引擎（NNUE，正常玩法明子局面）。
  本项目已内置适配器并修正 UCCI 坐标/FEN 约定。把引擎下载到
  `engine/bin/pikafish/` 即可自动启用（该目录已加入 `.gitignore`，不会随仓库推送）：
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\fetch_pikafish.ps1
  ```
  也可在“设置”中手动指定 `pikafish.exe` 路径。思考时间默认 2 秒、深度上限 64。
- **内置搜索引擎**：α-β + 迭代加深，正常玩法离线兜底（深度受时间限制，约 2~4 层）。
- **揭棋专用快速搜索**：揭棋分支极大（每节点约 100~270 个合法走法），旧版 2 秒内只算 1 层；现改为就地 make/unmake + 吃子优先排序 + 宽度控制的专用搜索，中局可达 3~4 层、小盘面更深，能预判对手回手。仍保持“暗子身份由用户确认、程序不猜测”。
- **内置开局库**：内置引擎在正常玩法开局命中常见棋谱时毫秒级返回主流定式（炮二平五对屏风马/顺炮/列炮/反宫马、仙人指路对卒底炮、左马盘河等），不命中才进入搜索；Pikafish 因自身棋力足够，直接由它搜索。
- ElephantEye 适配接口已预留；MockEngine 用于测试。

## 揭棋规则（预置 A 默认值）

| 项 | 默认 |
|---|---|
| 初始布局 | 将/帅固定原位且亮明；其余 15 子/方暗置在己方初始位（不参与随机） |
| 暗子走法 | 按所在初始格原兵种走法（如炮位按炮走） |
| 暗子吃子 | 按模板可吃子；吃子/移动后揭示身份（由用户录入） |
| 翻子 | 允许原地翻子（算一步，翻后不能再走） |
| 士/象限制 | 揭棋中 士/仕 可出九宫、象/相 可过河；将/帅 仍只能在九宫内走动 |
| 胜负 | 吃掉对方将/帅即胜（将/帅不暗置，固定原位） |

> 不同平台揭棋规则存在差异。若你以某平台规则为准，请修改 `rules/dark_presets.py` 或告知作者，
> 需要确认的问题清单见 `docs/dark-chess-presets.md`。即使规则不同，也可用“编辑棋局/强制录入”修正。

## 目录

```
main.py            入口
app/               配置/日志/常量
ui/                PySide6 界面（棋盘、对话框、分析面板）
core/              数据模型（棋子/棋盘/走法/状态/事件）
rules/             规则（BaseRules + NormalRules + DarkChessRules）
ai/                AI（统一引擎接口、搜索、评估、分析服务）
engine/            UCCI 客户端 + Pikafish/ElephantEye/Mock 适配
services/          服务层（游戏会话、录入、AI 调度、存档、设置）
models/            配置与分析结果模型
assets/            资源（预留）
tests/             单元测试
docs/              设计与规则文档（含揭棋预置、开局库说明）
```
