# 内置开局库（Opening Book）

为了让内置 AI 在开局阶段走出主流定式（而不是低层数搜索“发明”怪招），
`ai/opening_book.py` 内置了一个**纯本地、可离线**的开局库。

> 定位：只影响“推荐哪一步”。所有招法仍走统一合法走法校验；
> 本程序不联网、不自动读取/发送棋步，开局库不会把任何一步当作“必胜”保证。

## 数据来源

棋谱行（`BOOK_LINES`）来自网上公开棋谱/文章整理（正常玩法开局主线）：

- 华工象棋论坛《布局释疑》系列（hgchess.com）
- xqdao《弈林新编 · 杨官璘》（顺炮直车对横车等）
- xqipu 棋谱站常见开局库
- 百度百科“平炮兑车”等条目经典序列
- 其他常见定式（五七炮进三兵、左马盘河、列手炮、反宫马、仙人指路对卒底炮等）

收录行共 13 条，约 100 个“局面 → 走法”条目；解析时逐招用真实规则验证合法性，
某行后续招法无法走通时自动保留已走通的前缀，因此**不会收录不合法招法**。

## 解析原理

1. 对每条棋谱，从初始盘面开始，按红黑交替推进。
2. 每一步把棋谱文字记谱与 `core/notation.format_move` 的输出做规范化比对
   （含“一二三…九”与阿拉伯数字归一化），在当前方**合法走法**中精确匹配。
3. 匹配成功才把该“局面 → 落点对”写入表；匹配失败即停止该行，保留前缀。
4. 查询以 `GameState.position_key()` 为键（棋盘 + 轮到方），命中即返回书招。

## 如何生效

- 只用于**正常玩法**；揭棋暗子随机，不使用开局库。
- 命中时机：轮到方与棋谱一致、局面完整等于书内局面、且未超过书内深度上限
  （`OpeningBook.max_book_ply`，默认 24 步）。
- 生效位置：内置引擎 `ai/search.py::AlphaBetaEngine.get_best_move`。
  命中后**毫秒级返回**（不再做低深度搜索）；未命中则照常进入 α-β 搜索兜底。
- 因此对家手动录入走法后，AI 自动代走（或“分析我的最佳走法”）会优先走书招。

## 局限（不会谎称必胜）

- 棋谱只覆盖常见开局主线；对手走出冷门/变招后会自动退回搜索。
- 开局库给出的仍是“常见棋谱招法”，不代表“这一步一定赢”。
- 中局之后的水平取决于内置搜索（默认约 3 层）或你配置的 Pikafish 引擎。
  若希望中局更强，可在“设置”中改用 Pikafish 或增大思考时间。

## 如何扩充

新增一行 `BOOK_LINES`（红黑交替的 ASCII/中文记谱，如 `"马8进7"`、`"车一平二"`）即可；
解析器会自动校验并只收录合法前缀。添加后运行：

```
.venv\Scripts\python.exe -m pytest tests/test_opening_book.py -q
```
