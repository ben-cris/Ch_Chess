# 揭棋规则预置说明

揭棋没有唯一标准。本项目用 `rules/dark_presets.py` 中的 `DarkPreset` 表达规则差异，
默认启用 **preset_a**。

## 预置 A（默认，用户确认版）

**核心规则（2026-09 确认）：**
- 暗子（未揭示棋子）的“暗子行动”按该子**所在初始格原本棋子**的走法执行（位置模板）。
  例：位于炮位的暗子按炮的走法行动；位于车位的暗子按车走；位于兵位的暗子按兵走。
- 暗子移动或吃子后**必须揭示身份**（由用户选择真实身份，程序不猜测）；此后按真实身份走。
- 允许原地翻子（算一步，翻后本回合不能再走）。
- **士/象放宽**：揭棋中 士/仕 可出九宫、象/相 可过河（不再受宫/河限制）；
  **将/帅仍只能在九宫内走动**。
- 初始布局：**将/帅不参与随机揭棋**，红帅(9,4)、黑将(0,4)固定原位且亮明；其余 15 子/方暗置在己方初始格位（格位决定暗子走法模板）。

| 字段 | 取值 | 含义 |
|---|---|---|
| `hidden_uses_position_template` | True | 暗子按所在初始格原兵种走法行动 |
| `allow_in_place_reveal` | True | 允许原地翻子（算一步） |
| `dark_move_reveals` | True | 暗子行动后必须揭示身份 |
| `dark_move_capture` | True | 暗子按模板可吃子 |
| `revealed_king_facing` | True | 已揭示将/帅之间适用“照面”规则 |
| `capture_king_wins` | True | 吃掉将/帅即胜 |
